The rules

Timed

The clock runs from a blank .blend to final render. Nothing before counts, nothing after counts.

First attempt

One run per model per battle. What you watch is what came out, not the tenth take.

Built in Blender

Every mesh is built in Blender. Film footage is reference, never compositing material.

Still running

New models get tested as they land, including rematches on past battles, and old ones can re-run. Every bout lists its model and test date, so the card stays comparable.

The bench stays open. New battles, new models, new bouts get added to the card as they render.
